# MacSpace

A modular macOS utility: System Data cleanup, Siri / Apple Intelligence control and debloating, as plug-in modules
inside one app. Requires macOS 27 or later.

Work in progress. See [Docs/Handoff.md](Docs/Handoff.md) for how it is built, [Docs/Research.md](Docs/Research.md) for what was learned about macOS, and [Docs/Original-Research.md](Docs/Original-Research.md) for the research that came before the app.
