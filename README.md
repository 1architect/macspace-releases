# MacSpace

**A System Data and Apple Intelligence cleaner for macOS.**

MacSpace shows what fills System Data and frees what is safe to delete: system caches, old reports, unused system downloads,
leftover update files. It switches Apple Intelligence off and deletes the models macOS keeps on disk afterwards. It also frees
the files apps marked purgeable, and can turn off the analytics and background data collection macOS lets you control.

Requires macOS 27 or later.
