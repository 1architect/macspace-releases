# Contributing to MacSpace

Report bugs, suggest features and corrections, or ask about a contribution through
[GitHub Issues](https://github.com/1architect/macspace-releases/issues).

For a bug, include your macOS version, MacSpace version, what you expected and what happened.
Attach a screenshot or recording when it helps, after removing personal information. Never post
passwords, account details or other private data.

For a translation, include the language, the current wording and your suggested correction.
Discuss larger changes in an issue before opening a pull request.

Report security problems privately using the [Security Policy](SECURITY.md).
Everyone who participates follows the [Code of Conduct](CODE_OF_CONDUCT.md).
Contributions use the project's [MIT License](LICENSE).
